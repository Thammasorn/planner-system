# Excel: Workload Planner (ระบบเดิมที่ทีมใช้)

ไฟล์: `Workload_Planner_Aug-Dec_2026_v2.xlsx` (ฉบับล่าสุด) · ช่วง 18 สัปดาห์ 31 ส.ค. – 28 ธ.ค. 2026 · สัปดาห์เริ่มวันจันทร์

## Mental model ที่ผู้ใช้คุ้นเคย (ต้องรักษาไว้)

- **1 แถว = 1 คน × 1 โปรเจค × 1 คำอธิบายงาน**
- ใส่ **สัดส่วน 0–1 ต่อสัปดาห์** — 1.00 เต็มเวลา · 0.75 หนัก · 0.50 ครึ่งเวลา · 0.25 ซัพพอร์ต · ว่าง = ไม่ทำ
- ผลรวมทุกโปรเจคของคนหนึ่งต่อสัปดาห์ไม่ควรเกิน 1.00
- สี: แดง > 1.00 · เขียว 0.80–1.00 · เหลือง < 0.80
- ความแน่นอน 2 ระดับ: `แน่นอน` / `อาจไม่ทำ` ตั้งที่โปรเจค และ override รายแถวได้
- เทียบ 2 ฉาก: "ถ้าทำทุกอย่าง" vs "เฉพาะงานที่ยืนยันแล้ว"

ในเว็บ: สัดส่วน f ↔ `f × weekCapacity` person-day (SPEC BR-01, FR-804) — หน่วย default ของเว็บคือ "วัน" แต่ผู้ใช้สลับเป็นสัดส่วนได้

## ชีตและสูตร

| ชีต | เนื้อหา | ใน SPEC |
|---|---|---|
| `Setup` | B5:B12 พนักงาน (8) · D5:D16 บริษัท (12) · F5:F29 โปรเจค (25) · **G5:G29 ความแน่นอนของโปรเจค** | `user`, `clients`, `projects.certainty` |
| `Plan` | A บริษัท · B Project · C Description · D Person · **E ความแน่นอน (แถวนี้)** · F:W 18 สัปดาห์ · X รวม · Y จำนวนสัปดาห์ · Z Peak · **AA สถานะที่ใช้จริง** | `tasks`, `task_assignments`, `allocations`, BR-35 |
| `Timeline รายคน` | บล็อกต่อคน: แถวต่อโปรเจค + แถวรวม 2 ฉาก + คอลัมน์สถานะ (แน่นอน/อาจไม่ทำ/ผสม) | หน้ารายคน FR-1008 |
| `Workload รายคน` | 3 บล็อก: ฉาก A ทั้งหมด · ฉาก B เฉพาะยืนยัน · ส่วนต่าง A−B; แถวสรุป ทีมรวม / % ใช้กำลังคน / จำนวนคนที่ overload | FR-1001–1003, BR-37 |
| `สรุปรายโปรเจค` | ต่อโปรเจค: ความแน่นอน · ภาระรายสัปดาห์ · รวมทั้งหมด · รวมเฉพาะยืนยัน · จำนวนคน · เริ่ม · จบ · Peak | FR-409 |
| `แจ้งเตือน Overload` | `OVER x.xx` (เกินแม้ตัดงานไม่ชัวร์) · `เสี่ยง x.xx` (เกินเฉพาะถ้าทำทุกอย่าง) | BR-40 |

### สูตรสำคัญ → domain rule

| Excel | เว็บ |
|---|---|
| `Plan!AA` = `IF(E<>"", E, IFERROR(INDEX(Setup!G, MATCH(B, Setup!F, 0)), "แน่นอน"))` | `effectiveCertainty` BR-35 (เว็บเพิ่มการสืบทอดผ่าน task แม่) |
| `SUMIFS(Plan!week, Plan!D, person)` | `load(user, week, 'total')` |
| `SUMIFS(Plan!week, Plan!D, person, Plan!AA, "แน่นอน")` | `load(user, week, 'committed')` |
| `IF(committed>1,"OVER "…, IF(total>1,"เสี่ยง "…,""))` | `overloadStatus` BR-40 — เว็บเทียบกับ capacity จริง ไม่ใช่ 1.00 คงที่ |
| capacity = 1.00 คงที่ | `weekCapacity` BR-10–13 (หักวันหยุด/วันลา/พาร์ตไทม์) |
| สีแบบ conditional formatting | BR-45 |
