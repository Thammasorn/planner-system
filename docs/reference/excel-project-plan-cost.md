# Excel: Project Plan & Cost Template (อ้างอิงเท่านั้น — ไม่อยู่ใน MVP)

ไฟล์: `Project_Plan_Cost_Template.xlsx` · 1 ไฟล์ = 1 โปรเจค · ตัวอย่าง "Credit Scoring POC" ของ ABC Bank

> **สถานะ:** เจ้าของผลิตภัณฑ์ใส่ไฟล์นี้ไว้ในโฟลเดอร์เดียวกัน แต่ **SPEC.md ยังไม่รวมฟีเจอร์ต้นทุน** — ห้าม implement จนกว่า SPEC จะถูกแก้ (อยู่ในรายการ Phase 2+ ที่รอยืนยัน SPEC §13)

## ชีต

| ชีต | เนื้อหา |
|---|---|
| `เริ่มที่นี่` | ข้อมูลโปรเจค (ชื่อ, ลูกค้า, วันเริ่ม, จำนวนสัปดาห์ 1–26, วันทำงาน/สัปดาห์, สกุลเงิน) · **Rate card**: รหัส, ตำแหน่ง, ค่าแรง/เดือน → /สัปดาห์ (÷4) → /วัน (÷วันทำงาน) · **รายการ Stage** (Kick off, Requirement & Data, Data Preparation, Development/Modeling, Testing & Validation, Deployment, Analysis & Presentation, Project Management) |
| `Plan` | แถว = **งาน × ตำแหน่ง (ไม่ใช่ตัวคน)** · ใส่ **man-week** ต่อสัปดาห์ W1–W26 (0.5 = ครึ่งสัปดาห์, 2 = ใช้ 2 คน) · ต้นทุน = man-week × ค่าแรง/สัปดาห์ของตำแหน่ง · บล็อก "ต้นทุนอื่น" (Cloud, License, Travel) เป็นบาทต่อสัปดาห์ |
| `สรุปรายสัปดาห์` | man-week และต้นทุนค่าแรง แยกตามตำแหน่ง × สัปดาห์ |
| `สรุปโครงการ` | man-week รวม · ต้นทุนค่าแรง · ต้นทุนอื่น · ต้นทุนรวม · เฉลี่ยต่อสัปดาห์ · แยกตาม Stage |
| `Assumption & Risk` | วัตถุประสงค์ · สมมติฐาน · นอกขอบเขต · ตารางความเสี่ยง (ผลกระทบ, โอกาส, แผนรับมือ, ผู้รับผิดชอบ) |

Named ranges: `NWeeks`, `RateTable`, `RoleList`, `StageList`, `StartDate`

## ความสัมพันธ์กับ SPEC ปัจจุบัน

| แนวคิดใน Excel นี้ | ใน SPEC.md |
|---|---|
| Stage | ใช้ **task แม่** แทน (SPEC D8) |
| ตำแหน่ง / role code | `positions` มีอยู่แล้ว แต่ใช้จัดกลุ่มคน ไม่ได้ใช้คิดเงิน |
| วางแผนด้วย **ตำแหน่ง** ก่อนรู้ตัวคน | **ไม่มี** — SPEC วางแผนด้วยตัวคนเท่านั้น (task ที่ยังไม่มีคน = "รอมอบหมาย" ไม่มีภาระ) |
| man-week | = person-day ÷ 5 |
| Rate card, ต้นทุนค่าแรง, ต้นทุนอื่น | **ไม่มี** |
| Assumption & Risk | อยู่ใน template Project Charter แล้ว (SPEC Appendix B.1) |

## ถ้าจะเพิ่มในอนาคต (ร่างแนวคิด ยังไม่ใช่ requirement)

- Rate card ต่อตำแหน่ง (ค่าแรง/วัน) — เห็นได้เฉพาะ manager
- ต้นทุนค่าแรงของโปรเจค = Σ (person-day × rate ของตำแหน่งของคนนั้น)
- "ผู้รับผิดชอบชั่วคราวตามตำแหน่ง" (placeholder) เพื่อประมาณการก่อนรู้ตัวคน
- ต้นทุนอื่นรายสัปดาห์ต่อโปรเจค
