> Depends on: M7 ✅ (and M3, M5, M6, M6.1 through it) · SPEC v3.3: §4.8.1 (FR-810…820, AC-806…813), §5.12 (BR-100…105),
> §3.2 (new row "เส้นกำกับบนแผนงาน" = PERM-29; reads = PERM-06), §3.3 (chart/footer numbers only; markers per project),
> §6.2 (`plan_marker_color`, `plan_markers`, preference keys `plan.view`, `grid.showAssignees`, `grid.taskColumnWidth`, `grid.chart`),
> §7.1 (Charts row — `@mui/x-charts`), §7.2, §7.5 (move + marker undo), §7.10, §8.3 (sketch v3.3), §8.6, §8.13, §9 (M7.1 row = NFR-13),
> §11.1 (M7.1 row), §12 M7.1, §14 D21–D25 ·
> Owner-visible result: in a project's **แผนงาน** tab you can switch **[แผนงาน | ปฏิทิน]** to a Thai, Monday-first month calendar where
> tasks are bars from start to due date with assignee names; open a **กราฟภาระ** pane under the grid with one line per person over the
> visible weeks (load vs capacity, "รวมงานโปรเจคอื่น", a table view); drag the **งาน** column wider (remembered per user); drag task rows
> up/down (or `Alt+↑/↓/→/←`) to reorder them exactly like the task list; see **งาน** and **ผู้รับผิดชอบ** as two columns and hide the
> assignee column to get one row per task with summed numbers; read a **month-year row** above the weeks with month boundary lines; and add
> red / yellow / green **เส้นกำกับ** at the right edge of any column, with an optional label, shared with the whole project.
